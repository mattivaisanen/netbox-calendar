{% comment %} Shared by the calendar's form widgets (forms.py). Included by each widget but set up once per page; it runs again after HTMX swaps part of a form. - Date pickers: NetBox's flatpickr starts weeks on Sunday and is not set up again after HTMX swaps. This sets them up with the calendar's first weekday and shades Saturdays and Sundays. - Tabs (TabbedGroups): shown as tabs joined to the field under them, and the open tab is kept in a hidden field (TabChoiceInput) so the form knows which value to use. Switching tabs counts as a change of the form (the next times of a repeat are worked out again). {% endcomment %}
